# PyWorldAtlas documentation site

This repository hosts the published documentation for
[PyWorldAtlas](https://github.com/jcari-dev/pyworldatlas), an offline
world-geography package for Python.

**Read the documentation:
[jcari-dev.github.io/pyworldatlas-documentation](https://jcari-dev.github.io/pyworldatlas-documentation/)**

The files here are generated. Every page is built from the `docs/` folder of
the main repository and replaced on each deployment, so edits made here are
overwritten.

- Report a documentation problem or suggest an improvement:
  [jcari-dev/pyworldatlas/issues](https://github.com/jcari-dev/pyworldatlas/issues)
- Edit the source pages: [`docs/source`](https://github.com/jcari-dev/pyworldatlas/tree/main/docs/source)
- Plain-text indexes: [`llms.txt`](https://jcari-dev.github.io/pyworldatlas-documentation/llms.txt)
  and [`llms-full.txt`](https://jcari-dev.github.io/pyworldatlas-documentation/llms-full.txt)
