Changelog

This record summarizes user-visible package, data, documentation, and release changes. The newest published release appears first.

0.12.1

A more welcoming atlas, honest licensing, and up-to-date documentation.

  • Welcome: a “Look up anything” search on the home page, starting points for students, teachers, and developers, and a new Teaching with PyWorldAtlas guide.

  • Playground: Surprise me, a five-question quiz with a score, and three challenge recipes. See Playground.

  • Shorter pages: a shorter README, “In 30 seconds” examples, real output in guides, and Copy buttons on every code block.

  • Maps: place markers rest on the ground; the blue layer is now “Water and ice”.

  • Licensing: the package metadata reads MIT AND CC-BY-4.0 AND Unicode-3.0 AND CC0-1.0, matching the data it ships. The wheel includes the CC BY 4.0 text and the third-party notices, which list every source with its terms and the changes made.

  • Removed: six fields that were always empty (Area.disputed_km2, Geography.centroid, CountryCodes.wikidata, Capital.largest_city, Capital.alternate_names, City.alternate_names) and the include_history argument of Country.to_dict and to_json, which had no effect.

  • Documentation: a refreshed home page, package description, quickstart, installation guide, and API overview.

0.12.0

The world in numbers, landmarks, and a new playground.

  • Statistics pack: eleven basic World Bank indicators for every country since 1960, such as population, life expectancy, forest area, and access to electricity. Time series, one-line charts, plain-language summaries, and sorting without judgement. See The world in numbers.

  • Landmarks pack: airports with scheduled flights and UNESCO World Heritage sites, found by code, name, category, or distance. See Airports and World Heritage.

  • New playground: look up any country or place and open the Python behind each answer; four new recipes. See Playground.

  • Learning: place quizzes (kinds of places, which is higher, which is closer to the equator) and antipodes (“dig through the Earth”).

  • Runs on small computers: every place pack now unpacks in under 300 MB of memory, and import pyworldatlas is faster.

0.11.1

Travel basics and the sun.

  • Travel basics for 245 countries and areas: Country.travel gives plug types (IEC letters A to N), the household mains voltage and frequency, and the driving side, from CC0 Wikidata statements. Country summaries show a “Travel” line, and three new learning topics (driving_sides, plug_types, mains_electricity) feed flashcards and quizzes.

  • Sun and seasons: sun() and pyworldatlas sun give sunrise, sunset, day length, and the noon sun height for any place and date, worked out offline. See Sun and seasons.

  • Dataset 2026.10.27.1, schema 8.

0.11.0

Every place on Earth.

  • A school atlas in every install. 207,664 places chosen by educational value, in about 2 MB: every country, region, and town of 5,000 people or more, and the mountains, volcanoes, lakes, rivers, deserts, islands, and landmarks people around the world know. Search by local or English name with search_places() and place(), and list what is nearby with places_near().

  • 11 million places with packs. pyworldatlas get places-explorer places-world adds every other place in the GeoNames gazetteer.

  • One search for everything. lookup() and pyworldatlas find return countries first, then cities, regions, mountains, lakes, and landmarks.

  • Places on 3D maps. Maps mark each country’s best-known towns, mountains and islands, lakes and seas, and landmarks as layers with their own shape, color, and toggle, plus a Find a place box. places_in() lists the same places.

  • New commands: pyworldatlas find, place, and near.

  • Places are stored in a compact column format (6 to 10 bytes each) with only the standard library and unpacked once into a local index on first search.

0.10.0

A big step toward 1.0. The public API is now guarded by a snapshot test, so any change to it is deliberate and listed here.

  • Instant lookups. Every Atlas keeps its own caches. Ranking by border count, neighbor quizzes, and nearest-place searches drop from hundreds of milliseconds to a few. Closing one atlas no longer slows the others.

  • Maps with zero dependencies. The 3D viewer is part of PyWorldAtlas and needs no Plotly. Map data installs once as a checksummed data pack with pyworldatlas get maps (or maps-lite), or offline from a file with pyworldatlas add. All 496 maps match the 0.9 output.

  • A new map page. The map fills the window beside one control panel (color, terrain height, labels, rotation, reset view, Save PNG), with light and dark themes and a phone layout.

  • Accessible maps and docs. Maps work from the keyboard, carry a plain-language description for screen readers, and announce changes. The documentation adds a skip link and WCAG AA colors.

  • Everyday country names such as “UK”, “Britain”, “Burma”, “UAE”, “DRC”, “Netherlands”, “The Gambia”, and “St. Lucia” now resolve. Dataset 2026.10.26.1 adds the reviewed aliases.

  • For developers: a typed package (py.typed), notebook fact cards, Atlas(data_dir=...), pyworldatlas.packs, CountryMap.to_dict(), and plain-text llms.txt documentation indexes.

  • Packaging: one PyPI project. The pyworldatlas-mapview and pyworldatlas-mapdata-* packages are retired; the maps extras remain so older install commands still work. See Migration from 0.0.x.
