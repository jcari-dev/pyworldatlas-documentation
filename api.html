How to read an entry

Each blue heading is a public Python signature. A property is read as an attribute, such as country.flag. A method is called, such as country.name_in("ja"). Text after the colon is the return type; | None means the value may be unavailable in the bundled source layer.

Public records are frozen dataclasses. Repeated values are tuples, and a missing collection is empty. Use to_dict() or the corresponding model’s to_dict() method when you need JSON-compatible data.

Note

Atlas owns the read-only database connection. Use it as a context manager. Models already returned by the atlas remain usable after the context closes.

Atlas

The main entry point. Atlas handles country, city, and place lookup; nearby-place search; filtering; distances, sun times, and antipodes; border paths and rankings; flashcards and quizzes; dataset metadata; and the optional maps, landmarks, and statistics packs.

The examples on this page assume an open atlas, made with from pyworldatlas import Atlas and atlas = Atlas(). Every example is run as a test, so what you see is what you get.

class pyworldatlas.Atlas[source]

Open and explore the bundled, read-only world atlas.

With no arguments, Atlas uses the SQLite dataset shipped inside the package. Pass database_path only when working with a compatible database built by the PyWorldAtlas pipeline. A context manager closes the database promptly; already materialized immutable models remain usable. Runtime lookups and calculations require no network access.

data_dir selects the folder of optional data packs, such as 3D maps. It defaults to PYWORLDATLAS_DATA or a per-user folder; see pyworldatlas.packs.

Atlas.country(query: str) → Country[source]

Return one country profile resolved from a name or standard code.

query may be a familiar English name, indexed alias, alpha-2 code, alpha-3 code, or three-digit M49 code. Matching is case-insensitive and accent-tolerant. Missing queries raise CountryNotFoundError, with suggestions when available. A name shared by multiple profiles raises AmbiguousCountryError and lists the matches.

Parameters:

query – A country name ("Japan"), alias, alpha-2 code ("JP"), alpha-3 code ("JPN"), or M49 code ("392").

Returns:

The full Country profile.

Raises:

  • CountryNotFoundError – Nothing matches. The message suggests close spellings, such as “Did you mean Japan?”.

  • AmbiguousCountryError – The name fits more than one country.

Example

>>> atlas.country("Japan")
Country(name='Japan', alpha2='JP')
>>> atlas.country("DE").name
'Germany'
>>> atlas.country("392").name
'Japan'
Atlas.get(query: str, default: Country | None = None) → Country | None[source]

Return a matching country, or default instead of raising.

Use country() when a missing profile should be treated as an error. default is returned for both missing and non-unique queries.

Parameters:

  • query – A country name or code, as for country().

  • default – What to return when nothing matches.

Returns:

The Country, or default.

Example

>>> atlas.get("FR")
Country(name='France', alpha2='FR')
>>> atlas.get("Atlantis") is None
True
Atlas.find(query: str, *, limit: int = 10) → tuple[Country | Place, ...][source]

Find anything by name: countries, cities, regions, and landmarks.

One search for human-entered text. A country that the query names exactly (by name, alias, or code) comes first as a full Country profile; then come the best-known places from search_places(), where a country-level place is replaced by its Country profile. atlas.find("Luxembourg") gives the country and then its capital city.

Parameters:

  • query – Any name, such as "Luxembourg" or "Kilimanjaro".

  • limit – The most results to return.

Returns:

Country profiles and Place records, best first.

Example

>>> atlas.find("Luxembourg", limit=2)
(Country(name='Luxembourg', alpha2='LU'), Place(english_name='Luxembourg', kind='capital city', country_code='LU'))
Atlas.search_countries(query: str, *, limit: int = 20) → tuple[CountryMatch, ...][source]

Return ranked partial-name matches for human-entered text.

Matching is case-insensitive and accent-tolerant. Exact matches rank before prefixes and substrings. The returned tuple is empty when no indexed name matches; use country() for exact resolution.

Parameters:

  • query – Part of a country name, such as "guin".

  • limit – The most matches to return.

Returns:

CountryMatch rows, best match first.

Example

>>> atlas.search_countries("guin", limit=3)
(CountryMatch('Guinea'), CountryMatch('Guinea-Bissau'), CountryMatch('Equatorial Guinea'))

Return one exact bundled city, optionally limited to a country.

Atlas.search_places(query: str, *, kind: str | None = None, category: str | None = None, country: str | None = None, limit: int = 10) → tuple[Place, ...][source]

Find places on Earth by name, best known first.

Searches the bundled school atlas (about 200,000 places: every country, region, town of 5,000 people or more, and well-known mountain, lake, river, island, and landmark) plus any installed place packs. Local and English names both match, without regard to case or accents: "Lake Titicaca" finds "Lago Titicaca". Exact names come first, then names that start with the query; better-known places break ties.

Narrow results with kind (see place_kinds()), category (see place_categories()), or country.

Parameters:

  • query – A name or the start of one.

  • kind – Keep only this kind, such as "lake".

  • category – Keep only this category, such as "water".

  • country – Keep only places in this country.

  • limit – The most places to return.

Returns:

Place records, best match first.

Example

>>> atlas.search_places("Titicaca", limit=1)
(Place(english_name='Lake Titicaca', kind='lake', country_code='BO'),)

Filter and rank

Pick countries that match, and put them in order.

Atlas.countries(*, continent: str | None = None, region: str | None = None, currency_code: str | None = None, language_code: str | None = None, script_code: str | None = None, timezone_id: str | None = None, coastal: bool | None = None, koppen_geiger_code: str | None = None, has_rivers: bool | None = None, has_lakes: bool | None = None, river: str | None = None, lake: str | None = None, climate_zone: str | None = None, land_borders: bool | None = None) → tuple[Country, ...][source]

Return countries alphabetically, keeping only those that match every filter.

This is the one place to filter countries. With no filters, every bundled profile is returned in display-name order.

Physical-data filters only include profiles covered by the relevant source layer. For example, coastal=False means a sourced coastline of zero kilometres; it does not treat missing coastline data as zero.

Parameters:

  • continent – Keep countries on this continent, such as "Africa".

  • region – Keep countries in this UN region or subregion.

  • currency_code – Keep countries using this currency, such as "EUR".

  • language_code – Keep countries with this language, such as "es".

  • script_code – Keep countries writing in this script, such as "Cyrl".

  • timezone_id – Keep countries in this time zone, such as "Asia/Tokyo".

  • coastal – True for a coastline, False for landlocked.

  • koppen_geiger_code – Older name for climate_zone.

  • has_rivers – Keep countries with (or without) listed major rivers.

  • has_lakes – Keep countries with (or without) listed major lakes.

  • river – Keep countries a river flows through; part of the name is enough, in any case.

  • lake – Keep countries with this lake; part of the name is enough.

  • climate_zone – Keep countries with this Köppen-Geiger zone, a code from climate_zone_codes() such as "Cfb".

  • land_borders – False for islands and other countries with no land border, True for the rest.

Returns:

Matching Country profiles, alphabetical.

Raises:

ValueError – The climate zone is unknown.

Example

>>> len(atlas.countries(continent="Africa", coastal=False))  # landlocked
16
>>> atlas.countries(river="Danube")[:3]
(Country(name='Austria', alpha2='AT'), Country(name='Bulgaria', alpha2='BG'), Country(name='Croatia', alpha2='HR'))
>>> len(atlas.countries(land_borders=False))
85
Atlas.rank(metric: str, *, year: int | None = None, limit: int | None = None, descending: bool = True, continent: str | None = None, region: str | None = None) → tuple[CountryRanking, ...][source]

Rank countries by anything the atlas can measure, largest first.

Parameters:

  • metric – A profile metric such as "area", "coastline", or "border_count" (all are listed in rank_countries()), or a statistic such as "life_expectancy" from indicators().

  • year – Rank a statistic for one year. Without it, each country uses its latest published value, and the row’s year says which year that is.

  • limit – Keep only the first limit rows.

  • descending – False ranks smallest first.

  • continent – Rank only countries on this continent.

  • region – Rank only countries in this region or subregion.

Returns:

CountryRanking rows that print as #1 Canada: 202,080 km. Every row names its source. Missing values are left out, never guessed.

Raises:

ValueError – The metric is unknown. The message suggests a close spelling and lists the choices.

"population" ranks the bundled GeoNames snapshot; with a year it ranks the World Bank figures from the statistics pack. Ranking orders numbers only; it says nothing about which is better.

Example

>>> print(atlas.rank("coastline", limit=1)[0])
#1 Canada: 202,080 km
>>> atlas.rank("coastline", continent="Oceania", limit=2)
(CountryRanking('#1 Australia: 25,760 km'), CountryRanking('#2 New Zealand: 15,134 km'))
>>> atlas.rank("life_expectancy", year=2020, limit=1)
(CountryRanking('#1 Monaco: 86.1 years (2020)'),)
Atlas.sample_countries(*, count: int, continent: str | None = None, region: str | None = None, seed: int | str = 0) → tuple[Country, ...][source]

Return a reproducible educational sample of country profiles.

Candidates are ranked with a versioned SHA-256 algorithm using their stable M49 identifiers. Results therefore do not depend on SQLite row order, global random state, or implementation details of random.sample(). The same dataset, filters, count, and seed produce the same ordered result across supported Python versions.

count must be positive and cannot exceed the filtered population. continent and region follow countries() semantics.

Parameters:

  • count – How many countries to pick.

  • continent – Pick only from this continent.

  • region – Pick only from this region or subregion.

  • seed – The same seed always picks the same countries.

Returns:

The picked Country profiles.

Raises:

ValueError – count is not positive or is larger than the choices.

Example

>>> atlas.sample_countries(count=3, continent="Europe", seed="class-1")
(Country(name='Andorra', alpha2='AD'), Country(name='Hungary', alpha2='HU'), Country(name='Monaco', alpha2='MC'))

Results are alphabetical. language_code and script_code are optional, case-insensitive exact filters such as "es", "hi", "Deva", or "Jpan". Every UN M49 record has one selected local identity. Inspect LocalizedName.kind to distinguish reviewed national official forms from CLDR locale display names, or pass name_kind="national_official" or "locale_display" directly.

Parameters:

Returns:

Matching Country profiles, alphabetical.

Example

Atlas.countries_with_formal_names() → tuple[Country, ...][source]

Return countries and areas with a sourced English formal name.

Data packs

Install and locate optional PyWorldAtlas data packs.

A data pack is a .pack file (an uncompressed zip archive) that holds extra offline data, such as the 3D map editions. Packs are published as files on the project’s GitHub releases. Each library release pins the SHA-256 checksum of every pack it accepts, so a modified, damaged, or mismatched file is refused.

Normal use never touches the network. Only get() (pyworldatlas get) downloads, and only when it is called explicitly. Packs can also be installed from a local file with add(), for example on a machine without internet.

Packs are stored in one folder, chosen in this order:

  1. the data_dir argument (also accepted by pyworldatlas.Atlas);

  2. the PYWORLDATLAS_DATA environment variable;

  3. a per-user folder: %LOCALAPPDATA%\PyWorldAtlas\packs on Windows, ~/Library/Application Support/PyWorldAtlas/packs on macOS, and $XDG_DATA_HOME/pyworldatlas/packs (default ~/.local/share) elsewhere.

Data contracts and provenance

Country identity

Country.name is the familiar English display and lookup name. Country.official_name is the canonical English UN M49 identity, while Country.formal_name is the sourced English long or formal identity when that source layer covers the profile.

Country.local_names contains the selected sourced local identity. name_in(), official_name_in(), and the romanization helpers project values from that record; they do not translate or romanize text at runtime. Each LocalizedName retains its language, script, evidence kind, source, and source locator. See Local names and writing systems for the complete evidence rules.

Reference and discovery facts

Anthem, motto, demonym, currency, language, timezone, and postal records expose their contributing source when one is bundled. Country.sources lists sources used somewhere in the profile; it is not a field-by-field provenance map. See Country reference facts for coverage and interpretation rules.

Country.summary is presentation-ready text that omits unavailable facts. Use model attributes, to_dict(), or discovery_card() when a stable structured shape matters. Rankings describe sourced or directly calculated values; they do not score or judge countries. Quiz and flashcard helpers are deterministic and do not store learner answers or sessions.

Physical geography

Country.physical contains coastline, elevation points, mean elevation, source-listed rivers and lakes, and climate. Country.geography.area contains total, land, and water area plus the directly calculated water percentage.

Köppen-Geiger shares describe the portion represented by the documented raster and polygon extraction. They are not site-level climate claims. River lengths and lake areas describe the complete source feature, including shared features, rather than only the portion within one profile. See Physical geography and Data quality and limitations for limits.

Coordinates, cities, and distance

Atlas.distance_between() accepts coordinates, two-item latitude/longitude tuples, cities, capitals, countries, and exact bundled city names. A country uses its primary-capital coordinates. Distances are great-circle surface measurements; compass labels are orientation aids, not route instructions.

Atlas.city() performs exact lookup and reports ambiguous names. search_cities() performs accent-tolerant partial matching, while cities_near() orders results by great-circle distance. Optional country arguments narrow the lookup or returned places.

Land borders

Neighbor and path methods use the reviewed, undirected border graph. Shortest paths are deterministic breadth-first searches over stored relationships. They do not use boundary geometry, maritime relationships, transport networks, or current crossing rules. See Land borders and paths for the accepted-edge policy and interpretation limits.

Publication scope

The public model focuses on stable geographic reference data rather than current affairs, opinion, or speculative narrative. Missing scalar values are None and are never invented to fill a source gap. See Educational purpose and editorial policy and Data sources and freshness for the publication and source policies.
